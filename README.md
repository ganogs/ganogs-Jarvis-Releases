# Jarvis Android Releases

This public repository distributes signed Android APK releases and update metadata for Jarvis.

- Source code remains private in the separate `ganogs/Jarvis` repository.
- The Android app checks `latest.json` for available updates.
- APK installation always requires confirmation in Android.
- Do not upload API keys, signing passwords, or private source code here.

The first release will be published after the app has a persistent signing identity configured.
